# 🔢 Calculator with Audio Feedback

A modern, responsive, and beginner-friendly calculator built using **HTML**, **CSS**, and **JavaScript**, with **audio click effects** for each button interaction. This project combines functionality with aesthetics to provide a smooth and fun user experience.

## 🚀 Features

- ✨ Beautiful UI with gradient background
- 🔊 Audio feedback on each button press
- 📱 Fully responsive design
- 🔁 Supports basic arithmetic operations: Addition, Subtraction, Multiplication, Division
- 🔄 Clear and backspace buttons included

## 📂 Technologies Used

- HTML5
- CSS3 (Gradient styling and responsive layout)
- JavaScript (with comments for understanding)
- Audio API for click sounds
